# Lifespan

A single-player life simulator for macOS. Each press of **Age Up** is one year: things happen, you choose, you live with the results, you die, and you can carry on as one of your children. It plays like the classic text life sims, with more depth: NPCs remember you, choices come back years later through event chains, money compounds through a working economy, records follow you, and a full cheat menu lets you change anything. No ads, no energy, no premium currency, no network.

## Playing

Start a **random life** or build one: name, gender, attraction, country, city, birth year, who raised you and how many siblings, traits, a gift for one skill (or a prodigy's gift), pick-only gifts such as quick study and luck with money, work, sport, music, crime or business, a background (family business, parents with plans, a famous parent, always moving, new arrivals, raised by a grandparent, a twin, adopted), starting stats, family wealth, an optional seed that replays a life, and a drawn character. The builder has skin, face, hair and colour, eyes, brows, nose, mouth, facial hair, glasses, clothes, hats and earrings, and every option is drawn on your own face. Or pick a **challenge**: a premised life with goals and a deadline. The main screen has your stats and traits on the left, the life log in the middle, and four tabs on the right:

- **Occupation**: school grades, university and graduate school, job listings with filters, your job (work harder, raises, promotions, quitting, retirement), part-time work and freelance gigs, a business of your own (open it, grow it, hire a manager, sell it), the military, music and fame, and your legal record.
- **Assets**: cash, savings, investments, loans, homes for sale (cash or mortgage), vehicles, possessions, lifestyle, and the Finances view with last year's breakdown and a net-worth graph.
- **Relationships**: family, partners, children, friends, pets, and everyone else, each with a drawn face (relatives look like you). Click someone to see what they remember about you and to interact. The family tree shows three generations each way.
- **Activities**: health, social, love (18+), money, fun, travel, admin, crime, and prison activities, plus illness treatments and moving abroad. A year only holds so much free time, and you can give some of it to a focus: one skill or language you practise year after year (children and the gifted learn fastest, and a child far ahead of their age gets noticed). Finding a date shows three people to choose from, the casino has a blackjack table, and prison has an escape you plan square by square.

Everyone ages on screen, from baby to grey, and their faces follow their mood. Pets (dogs, cats, rabbits, hamsters, parrots, goldfish, tortoises and horses) have their own bond, health and lifespan.

When you die you get an obituary with a life title and your face through the years, and you can continue as any living child. The Dynasty view keeps every generation and a legacy score, and the start screen keeps records across every life (oldest, richest, most children, most achievements). The free-time limit can be switched off in Settings, and Settings decides how often a random life starts with a background (off by default).

Teenagers can go out with someone their own age (14–17, two years apart at most): crushes, dances, notes and first heartbreak, with nothing physical described. Romance, sex and pregnancy between adults fade to black. Crime and drugs stay abstract.

## Controls

| Key | Action |
|---|---|
| Space | Age Up |
| 1 – 4 | Choose in a popup |
| Esc | Close the top window or panel (event popups need an answer) |
| ⌘1 – ⌘4 | Switch tabs (Occupation, Assets, Relationships, Activities) |
| ⌘K | Command palette: find any available action |
| ⌘S | Save |
| ⌘L | Lives |
| ⌘, | Settings |
| ? | Keyboard shortcuts |
| ` or ⇧⌘K | Toggle the cheat panel (also the Cheats menu) |

The game autosaves every year. The Lives screen loads, renames, deletes, exports, and imports lives. On the Mac, saves live in `~/Library/Application Support/Lifespan/saves/`.

## Cheats

Open the panel with backquote, ⇧⌘K, or the Cheats menu. Every command is a form in the panel and a line in the console along the bottom (autocomplete with Tab, history with ↑/↓, `help` and `help <command>`). Using a cheat marks the life as cheated (a badge and a note on the obituary) unless you switch the badge off in Settings; achievements still count.

## Installing on the Mac

The overnight build leaves an unsigned app at `release/Lifespan-darwin-arm64/Lifespan.app`. On the Mac:

```bash
bash overnight/install-mac.sh     # signs it ad hoc, copies it to /Applications, opens it
```

If there is no app in `release/`, build it natively from the repo (needs Node):

```bash
bash overnight/build-mac.sh
```

## Development

Requires Node 22. `npm ci`, then:

| Command | What it does |
|---|---|
| `npm run dev:web` | The game in a browser at http://localhost:5173 |
| `npm run dev` | The Electron app with hot reload |
| `npm run build` | Production builds: Electron main, preload, renderer, and the standalone web build |
| `npm run verify` | typecheck, lint, hygiene, unit tests, content check, simulation, build, e2e, Electron smoke |
| `npm test` | Unit and integration tests (Vitest) |
| `npm run content:check` | Content validator and DONE thresholds |
| `npm run sim` | 300 seeded lives: invariants and balance bands, `reports/balance-report.md` |
| `npm run sim:coverage` | 2,080 lives across eight bot personas, `reports/coverage-report.md` |
| `npm run e2e` | Playwright against the built web app |
| `npm run electron:smoke` | The built Electron app under xvfb |
| `npm run shots` | Screenshots of key screens into `reports/screenshots/` |
| `npm run dist:mac` | Unsigned darwin-arm64 `Lifespan.app` in `release/` |
| `npm run dist:linux` | Unpacked linux-arm64 build in `release/`; `npm run electron:smoke:packaged` tests it |
| `npm run docs:cheats` | Regenerate the cheat list above from the registry |

The engine (`src/engine`) is pure TypeScript with a seeded RNG stored in the game state, so a life is fully determined by its seed and your inputs. Content (`src/content`) is typed data: events, jobs, countries, illnesses, crimes, activities, achievements. Writing guidelines for events are in `src/content/events/GUIDE.md`.
